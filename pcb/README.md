# 表示ボード基板設計（PCBE / 片面エッチング）

DFPlayer + 74HC595×2 + 7セグ(2桁)用抵抗 を1枚にまとめた表示ボードの設計データ。
**片面エッチング・ベタGND・7segは基板外に端子で引き出し**の方針。

> [!NOTE]
> **設計途中**。PCBE で清書・エッチングする前の下図・座標・結線データ。
> 座標は叩き台で、PCBE 上での微調整を前提とする。

## 設計方針

- **片面**基板（ジャンパーは数本許容・コンパクト優先）
- **ベタGND**: 地の銅をGND面として残す → GND配線がほぼ消える。エッチングも楽
- **7seg は基板に載せない**: セグ16＋コモン2を18ピン端子で外へ出し、外壁の7segへ配線
  → 交差の主因が消えて信号が縦一直線になる
- 信号の流れ: **595出力(下) → 抵抗(中) → 7seg端子(上)** が一直線
- 5V は横一本のラインで各部品へ分岐
- 想定ジャンパー: 595間のSRCLK/RCLK共通線、カスケード(595#1 QH'→#2 SER) 程度

## 部品

| 部品 | 数 | 備考 |
|:-----|:--:|:-----|
| 74HC595 | 2 | カスケード（#1=右桁, #2=左桁） |
| DFPlayer Mini HW-247A | 1 | 直付け（チップ TD5580A） |
| 抵抗 470Ω | 16 | セグメント用（dp含む・R1〜R16） |
| 抵抗 1kΩ | 1 | DFP RX保護（R17） |
| 端子（ピンヘッダ） | — | 7seg用18 / Nano用7 / SPK用2 |

※7セグLED(A-552SRD)本体は基板外。端子から配線で接続。

## PCBE作業手順

1. `coords.md` を見て部品を座標通りに配置（左上原点・2.54mmグリッド・DIP1番ピン左上）
2. 抵抗16本を595の上に並べる（窮屈なら微調整）
3. 端子類を配置
4. `netlist.md` を見てピン間を配線
5. 地の銅を GND 面として残す（ベタGND）

## 検証済みの前提

- 595の QA〜QH = bit0=a 〜 bit7=dp（統合テストで動作確認済みのコードと一致）
- 595#1=右桁(一の位), 595#2=左桁(十の位)
- 7seg A-552SRD はアノードコモン（コモン→5V、セグメントは595出力LOWで点灯）
