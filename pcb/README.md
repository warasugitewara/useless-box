# 本体統合ボード設計（PCBE / 片面エッチング）

意味のない箱の**本体制御をすべて1枚にまとめた**基板の設計データ。
Nano・74HC595×2・DFPlayer・抵抗を載せ、サーボ/スイッチ/7seg/電源は端子で外に出す。

> [!NOTE]
> **設計途中**。PCBE で清書・エッチングする前の結線データ。配置はPCBE上で決める。
> R/C クローラーは別基板（[`../rc/`](../rc/)）で、本ボードには含まない。

## 基板に載る部品

- **Arduino Nano**（ピンソケットに挿す）
- **74HC595 × 2**（カスケード / #1=右桁, #2=左桁）
- **DFPlayer Mini HW-247A**（直付け・チップ TD5580A）
- 抵抗 **470Ω × 16**（R1〜R16・セグメント用）+ **1kΩ × 1**（R17・DFP RX保護）
- 各端子（端子台 / ピンヘッダ）

## 外部へ出す端子

| 端子 | ピン数 | 内容 |
|:-----|:------:|:-----|
| 電源A | 2 | +4.5V / GND |
| 電源B | 2 | +6V / GND |
| 7seg | 18 | セグ16＋コモン2 |
| サーボ フタ(SG90) | 3 | +4.5V / 信号(D5) / GND |
| サーボ 腕(MG996R) | 3 | +6V / 信号(D6) / GND |
| スイッチ | 2 | 信号(D12) / GND |
| スピーカー | 2 | SPK1 / SPK2 |

## 設計方針

- **片面**エッチング・**ベタGND**（地の銅をGND面として残す）
- **7seg は基板外**（18ピン端子で引き出し）→ 信号が縦一直線・交差減
- 信号: 595出力 → 抵抗 → 7seg端子 が一直線
- ジャンパー見込み: 595間のSRCLK/RCLK共通線、カスケード程度

## 電源設計（過去の教訓を反映）

- **電源A 4.5V**: Nano・表示系(595/DFP/7segコモン)・SG90(フタ)
- **電源B 6.0V**: MG996R(腕)専用
- ⚠️ **6V は 電源B端子 → サーボ腕端子へ直行**。Nano・信号系を通さない
  → MG996R の突入電流(最大2.5A)によるブラウンアウトを構造的に回避
- ⚠️ **電源A・BのGNDはベタGNDで共通**（別々だとMG996R誤動作）
- 6V経路（+6VとGND）は突入電流対応で**太いパターン**にする
- Nano給電は 4.5V を **5Vピンへ直結**（VINは6V以上必要なので使わない）

## Nano ピン割り当て

| ピン | 用途 |
|:----:|:-----|
| D2 / D3 / D4 | 7seg（595 DS / SH_CP / ST_CP） |
| D5 | SG90（フタ） |
| D6 | MG996R（腕） |
| D10 / D11 | DFPlayer（TX / RX・D11は1kΩ経由） |
| D12 | トリガースイッチ |
| A0 | randomSeed用（未接続で浮かせる） |

## ファイル

## PCBE作業手順

1. `wiring.md` を見て、基板に載る部品（Nano・595×2・DFP・抵抗）を配置
2. 端子（電源A/B・7seg・サーボ×2・スイッチ・スピーカー）を外周に配置
3. `wiring.md` の各行を1本ずつ配線（引くたびにチェック）
4. 地の銅を GND 面として残す（ベタGND・6V経路のGNDは太く）

## 検証済みの前提（統合テストで確認）

- 595 QA〜QH = bit0=a 〜 bit7=dp（動作確認済みコードと一致）
- 595#1=右桁(一の位), 595#2=左桁(十の位)
- 7seg A-552SRD はアノードコモン（コモン→5V、595出力LOWで点灯）
- DFP は playMp3Folder 方式、TD5580A 対策済み
