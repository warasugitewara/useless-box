# useless-box 表示ボード 座標表（PCBE配置用）

**基準**: 左上原点 (0,0) / 1グリッド = 2.54mm / X→右・Y→下 / DIP は1番ピン左上

座標は「グリッド番地」。実寸mm = 番地 × 2.54。PCBEのグリッドに合わせて配置し、配線は結線表を見て引く。

基板目安: 40×28グリッド ≒ 101.6×71.1mm

## 配置の考え方

- 595出力(下)→抵抗(中)→7seg端子(上) が縦一直線。交差なし。
- 5V は Nano端子から横一本で配り、595 VCC/SRCLR・DFP VCC・7segコモンへ分岐。
- GND はベタ（地の銅を残す）。595 GND/OE、DFP GND はその場で落とす。
- 想定ジャンパー: (a)595#1↔#2 のSRCLK/RCLK共通線、(b)カスケード 595#1 QH'→#2 SER。
- 全座標はPCBE上で微調整可。まず部品を置き、結線表で配線を引く。
