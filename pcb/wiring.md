# useless-box 本体統合ボード ピンtoピン結線リスト

表示部(DFP+595×2+7seg抵抗) に **本体(Nano・サーボ・スイッチ・2電源)** を統合した完全版。

1行 = 配線1本。PCBEで引くたび ☐→☑。R/Cクローラーは別基板（含まない）。

## 電源系統（重要）

- **電源A 4.5V**: Nano(5V/VIN)・7seg系(595/DFP/7segコモン)
- **電源B 6.0V**: MG996R専用。**電源B端子→サーボ端子へ直行**（Nano/信号系を通さない）
- **GND**: ベタGNDで全系統共通（電源A・B・信号すべて）。6V経路のGNDは太めに確保
- SG90(フタ)は電源A(4.5V)側、MG996R(腕)は電源B(6V)側

略号: 595#1=右桁 595#2=左桁 / DFP=DFPlayer / 7seg=A-552SRD / SV=サーボ / SW=スイッチ

7segピン: DIG.1→a16 b15 c3 d2 e1 f18 g17 dp4 com14 / DIG.2→a11 b10 c8 d6 e5 f12 g7 dp9 com13

## 設計上の要点（過去の教訓を反映）

- **6V(MG996R)は電源Bからサーボ端子へ直行**。Nano・信号系を通さない → ブラウンアウト回避
- **電源A・BのGNDはベタGNDで共通**（別々だとMG996R誤動作）
- 6V経路（電源B+とGND）は突入電流2.5A対応で**太いパターン**にする
- SG90は4.5V側、MG996Rは6V側で系統が違うので端子で分ける
