# 7seg エッチング基板の検証

[`pcb/7seg.pcb`](../../pcb/7seg.pcb) で作った 7seg 基板（74HC595 ×2 ＋ A-552SRD）を単体で確認するスケッチ。

## 配線（5本）

| Arduino | 基板 | 役割 |
|:--|:--|:--|
| `D2` | 右IC（595#1）14番 SER | データ |
| `D3` | 11番 SRCLK（2個共通） | シフトクロック |
| `D4` | 12番 RCLK（2個共通） | ラッチ |
| `5V` | 16番 VCC | 電源 |
| `GND` | 8番 GND | GND |

> [!WARNING]
> 電源を入れる前に、5V と GND の線の間が導通していないことをテスターで確認する
> （GND の線を 16番に挿してショートさせた前例あり）。

## 使い方

起動すると 全点灯 → セグメント1本ずつ → 00〜99 カウント を自動で1周する。
その後はシリアルモニタ（9600bps・改行あり）から操作。

| 入力 | 動作 |
|:--|:--|
| `0`〜`99` | その数を表示 |
| `a` | 全点灯 |
| `s` | セグメントを a→…→dp の順に1本ずつ点灯 |
| `c` | 00〜99 カウント |
| `o` | 全消灯 |
| `x` | 右桁の d/f 補正 ON/OFF |

基板では右桁の d と f が入れ替わって配線されているため、補正は既定で ON。

> [!TIP]
> 全点灯だけではデータ線の確認にならない（データ線が切れていても全点灯になる）。
> `o` で消えるか、`s` で1本ずつ正しく光るかまで見る。
