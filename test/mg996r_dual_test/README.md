# MG996R ×2 同時運用テスト

フタ・腕の両方を MG996R にしたときに、電源B（単三×4）を共用して問題なく動くかを確認するスケッチ。

## 配線

| 線 | つなぎ先 |
|:--|:--|
| 茶（GND） | 電源Bの − ＋ Arduino の GND（共通） |
| 赤（＋） | 電源Bの ＋（Arduino の 5V には繋がない） |
| 黄（信号） | フタ `D5` ／ 腕 `D6` |

## 使い方（シリアルモニタ 9600bps）

| 入力 | 動作 | 見るところ |
|:--|:--|:--|
| `1` | フタだけ 開→閉 | 動くか |
| `2` | 腕だけ 伸→戻 | 動くか |
| `3` | 本番と同じ順番 | 途中で止まらないか |
| `4` | 2個同時に動かす | Arduino がリセットしないか（電池の踏ん張り） |
| `r` | `3` を10回連続 | 電池の持ち・発熱 |
| `d` | 両方脱力 | — |

角度は箱に取り付ける前の仮の値。取り付け後にスケッチ先頭の定数で合わせる。
